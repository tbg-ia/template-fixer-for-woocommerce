# Changelog

All notable changes to Template Fixer for WooCommerce will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-01-13

### Added
- Template Updater integrated functionality
- Dashboard widgets for real-time monitoring
- Mass update feature with preview and validation
- Automatic backups with theme customizations preservation
- Verification system for plugin functionality
- Support for uTech theme customizations

### Changed
- Updated WordPress compatibility to 6.8
- Improved database query security
- Standardized text domain to 'template-fixer-for-woocommerce'

### Fixed
- Text domain mismatches in admin interface
- Database query compatibility for WordPress < 6.2
- Direct database query warnings
- Coding standards compliance

### Security
- Enhanced SQL query preparation
- Added proper escaping for database operations

## [1.0.0] - Initial Release

### Added
- Basic template scanning functionality
- Template version comparison
- Manual update capability
- Basic backup system
